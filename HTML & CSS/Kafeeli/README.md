# Kafeeli - Orphan Sponsorship Platform

A modern, responsive, and user-centric web platform designed to connect generous donors with orphans in need, featuring a clean Arabic UI/UX layout.

## Key Features:

- **Responsive Header & Navigation:** Clean top bar featuring the platform branding, intuitive navigation links, and a dedicated donation action button[cite: 8].
- **Hero Section:** Engaging introductory banner with high-impact typography, trust badges, call-to-action buttons, and a featured illustration[cite: 8].
- **Impact Statistics:** A prominent stats grid showcasing total sponsored orphans, overall contributions, and global outreach[cite: 8].
- **Why Choose Us (Features):** Highlights core platform pillars including human connection, transparency, and data privacy using custom card designs[cite: 8].
- **Orphans Directory:** Interactive profile cards displaying orphan details (Name, Age, Location) with direct sponsorship triggers[cite: 8].
- **Sponsorship Journey:** A step-by-step interactive breakdown illustrating the process from registration to impact tracking[cite: 8].
- **Footer & Direct Contact:** Comprehensive footer layout incorporating direct communication channels, location info, and copyright details[cite: 8].
