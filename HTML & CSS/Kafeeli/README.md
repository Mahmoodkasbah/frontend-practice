# Kafeeli - Orphan Sponsorship Platform

A responsive web platform built while practicing HTML and CSS.

The website presents a simple platform for orphan sponsorship, with sections for information about the platform, statistics, orphan profiles, sponsorship steps, and contact information.

## Features

- Responsive header and navigation
- Hero section with introduction and action buttons
- Statistics section
- Features section
- Orphan profile cards
- Sponsorship steps section
- Contact information and footer
- Responsive design for different screen sizes

## Technologies

- HTML
- CSS
