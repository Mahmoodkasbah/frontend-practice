# Dynamic Product Cards

A simple product cards layout built while practicing JavaScript and DOM manipulation.

The page is created mainly using JavaScript, including the header, navigation, product cards, and footer.

## Features

- Creates the page elements using JavaScript
- Generates 50 product cards using a loop
- Adds product information dynamically
- Creates a header and navigation menu
- Creates a footer
- Applies styles using JavaScript
- Uses Font Awesome icons
- Responsive product card layout

## Technologies

- HTML
- JavaScript
- Font Awesome

## What I Practiced

- DOM manipulation
- `document.createElement()`
- Adding elements to the page
- JavaScript loops
- Working with arrays
- Functions
- Using `element.style`
- Creating dynamic content with JavaScript
