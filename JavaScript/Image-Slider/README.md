# Dynamic Image Slider

A simple image slider built while learning and practicing JavaScript and Tailwind CSS.

The slider allows users to move between images using Next and Previous buttons, with slide indicators showing the current image.

## Features

- Next and Previous buttons
- Slide indicator dots
- Shows the current slide number
- Highlights the active slide
- Disables the Previous button on the first slide
- Disables the Next button on the last slide
- Responsive design
- Tailwind CSS styling

## Technologies

- HTML
- JavaScript
- Tailwind CSS
