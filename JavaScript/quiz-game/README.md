# Quiz Time

A simple quiz game built while learning and practicing JavaScript and DOM manipulation.

The quiz contains questions about **HTML, CSS, and JavaScript**, and shows the user's score at the end.

## Features

- 10 multiple-choice questions
- Shows whether the selected answer is correct or incorrect
- Displays the correct answer when the selected answer is wrong
- Tracks the score
- Shows the final result
- Restart the quiz and try again
- Responsive design for different screen sizes

## Technologies

- HTML
- CSS
- JavaScript

## What I Practiced

- DOM manipulation
- JavaScript arrays and objects
- Event listeners
- Conditional statements
- Functions
- Updating HTML elements with JavaScript
