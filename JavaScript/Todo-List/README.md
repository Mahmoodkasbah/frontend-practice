# My Tasks

A simple Todo List application built while learning and practicing JavaScript and DOM manipulation.

The app allows users to add, edit, complete, and delete tasks. Tasks are saved in the browser using `localStorage`, so they remain available after refreshing the page.

## Features

- Add new tasks with the current date
- Mark tasks as completed
- Edit existing tasks
- Delete tasks with a confirmation message
- Save tasks using `localStorage`
- Display the creation date
- Responsive design
- Font Awesome icons

- CSS
- JavaScript
- LocalStorage
- Font Awesome
